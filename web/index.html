Bootstrap Yield Curve

A quantitative finance toolkit — yield curve bootstrapping, Nelson-Siegel fitting, and Markowitz portfolio analysis.
Omar Jarir · GPL-3.0 · Python 3.8+  |  6 passing tests CI 3.9–3.12 Nelson-Siegel Efficient frontier

What it is

A Python package that builds a yield curve from coupon-bearing bonds using three bootstrapping methods, fits a Nelson-Siegel parametric curve, and runs a mean-variance portfolio analysis on an equity panel. It started as a single Jupyter notebook for a Computational Finance assignment in August 2022 and was refactored into a proper package with tests and CI in September 2026.

The original notebook is preserved untouched in notebooks/ — it still runs and documents the original step-by-step exploration. The package API lives in src/yield_curve/ and is what you'd use in production code.

What you get

Yield Curve Bootstrapping

YieldCurve class — discount factors via matrix solve, global solver, or iterative procedure; spot rates, YTM per bond, and 1-year forward rates.

Nelson-Siegel Fit

NelsonSiegel class — parametric curve (level, slope, curvature, decay) fitted by least squares to market discount factors. Smooths the jagged bootstrap.

Portfolio Analysis

PortfolioAnalyzer — daily returns, annualized mean/vol/Sharpe, correlation heatmap, cumulative returns plot. Risk-free rate optional (can come from the bootstrapped curve).

Efficient Frontier

Markowitz mean-variance optimization: scan target returns, minimize variance, find the maximum-Sharpe tangency portfolio. Optional yfinance connector for live data.

Quick example

from yield_curve import YieldCurve, NelsonSiegel

# 10 Treasury bonds: (maturity_years, price, coupon_rate)
bonds = np.array([
    [1, 96.60, 0.0150],
    [2, 93.71, 0.0175],
    [3, 91.56, 0.0200],
    # ... up to 10-year
], dtype=float)

yc = YieldCurve(bonds)

# Three methods — they all agree
df_matrix = yc.discount_factors('Matrix operations')
df_solver = yc.discount_factors('Global Solver')
df_iter   = yc.discount_factors('Iterative Procedure')

# Derived rates
spot  = yc.spot_rates()          # annual-compounded spot curve
ytm   = yc.bonds_ytm()           # yield to maturity per bond
fwd   = yc.forward_rates()       # 1-year forward rates

# Visualize
yc.plot_rates(title='US Treasury Yield Curve').savefig('yield_curve.png')

# Nelson-Siegel smooth fit
ns = NelsonSiegel(bonds[:, 0].astype(float), df_matrix)
ns.fit()
print(f'beta0={ns.params[0]:.4f}, beta1={ns.params[1]:.4f}, tau={ns.params[3]:.3f}')
ns.plot().savefig('nelson_siegel.png')

For the equity side: PortfolioAnalyzer takes a DataFrame of prices (columns = tickers, index = dates) and computes the efficient frontier, max-Sharpe portfolio, correlation heatmap, and cumulative returns.

Package vs. original notebook

2022

Original exercise — one notebook

A single Bootstrapping_Yield_Curve.ipynb with two exercises: (1) bootstrap a Treasury curve three ways and plot spot/YTM/forward rates; (2) fetch five tech stocks from Yahoo, compute returns, correlation, save CSVs. The code lived in notebook cells — no package, no tests, no CI.

2026

Package — same logic, engineered surface

The YieldCurve class moved to src/yield_curve/bootstrap.py. A NelsonSiegel class was added. The stock-data exercise became PortfolioAnalyzer with efficient frontier and max-Sharpe optimization. The package is tested (6+ tests on the core logic), has CI on 3.9–3.12, a pyproject.toml, and a demo.ipynb that imports it.

API reference

YieldCurve(bonds)

bonds: np.ndarray, shape (n, 3), columns = (maturity_years, dirty_price, coupon_rate). Face value = 100.

MethodReturns
discount_factors(method)np.ndarray (n,) — 'Matrix operations' / 'Global Solver' / 'Iterative Procedure'
spot_rates()np.ndarray (n,) — annual-compounded spot rates
bonds_ytm()np.ndarray (n,) — YTM per bond
forward_rates()np.ndarray (n-1,) — 1-year forward rates
plot_rates(title, save_path)plt.Figure — spot + YTM + forward on one chart

NelsonSiegel(maturities, discount_factors)

Fit a parametric curve f(t) = β₀ + β₁·e⁻ᵗ/ᵗ + β₂·(t/τ)·e⁻ᵗ/ᵗ to market discount factors by least squares.

MethodReturns
fit()self — solves for β₀, β₁, β₂, τ
fitted_discount_factors()np.ndarray — model DF over the input maturities
plot(market_df, save_path)plt.Figure — market vs fitted DF

PortfolioAnalyzer(prices, risk_free_rate=0.0)

prices: pd.DataFrame, columns = tickers, index = dates (daily close prices).

MethodReturns
efficient_frontier(n_points)pd.DataFrame — columns: volatility, return, sharpe, weights
max_sharpe_portfolio()dict — weights, volatility, return, sharpe
correlation_heatmap(save_path)plt.Figure — seaborn-style correlation matrix
cumulative_returns_plot(save_path)plt.Figure — cumulative returns per asset

Run it

# Clone
git clone https://github.com/omarja12/Bootstrap-Yield-Curve.git
cd Bootstrap-Yield-Curve

# Environment
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# Install the package + dev tools + yfinance (optional)
pip install -e ".[dev,yfinance]"

# Tests
pytest tests/ -v

# Open the demo notebook
jupyter lab notebooks/demo.ipynb

No network required for the yield curve module — it ships with the original bond data built in. The portfolio module needs yfinance for live data (or pass in your own DataFrame).
